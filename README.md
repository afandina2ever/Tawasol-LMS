# Tawasol.LMS — تطبيق أندرويد

تطبيق أندرويد بسيط (WebView) يفتح موقع المشروع بشكل يشبه تطبيقًا حقيقيًا على الموبايل:
شاشة كاملة بدون شريط عنوان المتصفح، دعم تسجيل الدخول والجلسات، رفع وتنزيل الملفات،
شريط تحميل، سحب للتحديث (Pull to refresh)، وزر رجوع ذكي.

## المميزات
- **الدومين قابل للتغيير من داخل التطبيق** — أول مرة يفتح المستخدم التطبيق، يُطلب منه إدخال
  رابط موقع مدرسته، ويُحفظ محليًا على الجهاز. يمكن تغييره لاحقًا من القائمة (⋮ > تغيير رابط الموقع).
- تسجيل الدخول والجلسة (الكوكيز) يبقيان محفوظين بين مرات فتح التطبيق.
- رفع الملفات يعمل بشكل طبيعي (من المعرض أو التقاط صورة بالكاميرا) — مطلوب لصفحات مثل
  "المواد التعليمية" و"استيراد Excel".
- تنزيل الملفات (تصدير Excel، طباعة PDF) يعمل عبر مدير التنزيلات في أندرويد ويظهر إشعارًا.
- روابط الاتصال / واتساب / تيليجرام تفتح تطبيقاتها الخاصة تلقائيًا بدل فتحها داخل الموقع.
- زر الرجوع في الموبايل يتنقّل داخل صفحات الموقع (مثل متصفح حقيقي) قبل الخروج من التطبيق.

## متطلبات البناء
- Android Studio (أحدث إصدار مستقر).
- لا حاجة لأي إعداد إضافي — المشروع جاهز، فقط افتحه في Android Studio واضغط Run أو Build > Generate Signed Bundle/APK.

## تغيير اسم التطبيق أو الحزمة (Package Name)
- اسم التطبيق: `app/src/main/res/values/strings.xml` → `app_name`.
- معرّف الحزمة (`com.tawasol.lms`): موجود في `app/build.gradle` (`namespace` و `applicationId`).
  لو غيّرته، لازم تغيّر مسار المجلدات تحت `app/src/main/java/` بنفس الاسم الجديد.

## استبدال الشعار (Icon) — الأهم
الشعار الحالي مؤقت وبسيط (حرف T داخل دائرة) فقط حتى ترفع تصميمك الخاص. لاستبداله:

**الطريقة الأسهل (موصى بها):**
1. افتح المشروع في Android Studio.
2. زر يمين على `app/src/main/res` > `New` > `Image Asset`.
3. اختر نوع `Launcher Icons (Adaptive and Legacy)`.
4. ارفع صورتك (يُفضّل مربعة، خلفية شفافة أو بسيطة، بحجم لا يقل عن 512×512 بكسل).
5. Android Studio سيولّد تلقائيًا كل الأحجام المطلوبة (mdpi حتى xxxhdpi + النسخة التكيّفية Adaptive).

هذا سيستبدل الملفات التالية تلقائيًا:
- `app/src/main/res/mipmap-*/ic_launcher.png` و `ic_launcher_round.png`
- `app/src/main/res/drawable/ic_launcher_foreground.xml`
- `app/src/main/res/drawable/ic_launcher_background.xml`

## نشر التطبيق (توليد APK / AAB للنشر على Google Play)
1. Android Studio > Build > Generate Signed Bundle / APK.
2. أنشئ مفتاح توقيع جديد (Keystore) واحفظه في مكان آمن — ستحتاجه لكل تحديث مستقبلي للتطبيق.
3. اختر **Android App Bundle (AAB)** لو ناشر على Google Play، أو **APK** للتوزيع المباشر.

## ملاحظة أمان (network_security_config.xml)
التطبيق مفعّل عليه السماح بالاتصال غير المشفّر (http) بشكل عام، لأن رابط الموقع يُدخله
المستخدم بنفسه وقد لا يملك شهادة SSL بعد. بعد ما يكون عندك دومين ثابت ومؤمّن بـ HTTPS،
يُفضّل تعديل `app/src/main/res/xml/network_security_config.xml` لتقييد الاتصال غير
المشفّر على هذا الدومين فقط (أو إزالته بالكامل) لحماية أفضل.

## هيكل الملفات المهمة
```
app/src/main/java/com/tawasol/lms/
├── SetupActivity.kt   — شاشة إدخال رابط الموقع (تظهر أول مرة فقط)
├── MainActivity.kt    — شاشة WebView الرئيسية (كل منطق التطبيق)
└── Prefs.kt           — تخزين الرابط المحفوظ محليًا

app/src/main/res/
├── layout/            — تصاميم الشاشتين
├── drawable/           — الشعار المؤقت (استبدله كما بالأعلى)
├── mipmap-*/           — أحجام الشعار الجاهزة لكل كثافة شاشة
└── values/strings.xml  — كل النصوص الظاهرة في التطبيق (لتعديلها)
```
